# 超・伝言バトル！

手話伝言ゲームの**進行ガイド＋スコア管理**サイト。2〜5人で楽しめるパーティーゲーム。

🎮 **遊ぶ**: https://kappamanager.github.io/cho-dengon-battle/

## 特徴

- VRMモデル＋Mixamoモーションで色分けされた棒人間が画面で踊る・ポーズする
- 場面ごとに別々のモーションプール（TOP / ゲーム中 / 結果発表など）から自動アサイン、同時に同じモーションが被らないように配る
- 制限時間タイマー、戻る／やり直し対応、同点優勝の表示も含めた採点ロジック

## 操作の流れ

1. ロード画面で「▶ はじめる！」→ TOP画面に BGM とともに突入
2. 人数（2〜5）→ 名前 → 順番 → 制限時間 を入力
3. ゲーム中は「読み上げ人を選ぶ → レベル1〜5を選ぶ → 正解者を選ぶ → 採点」を繰り返し
4. 「終了する」または時間切れで結果発表へ

## ローカルで動かす

ブラウザの自動再生規制と相対パス読込のため、**ローカルサーバ経由**で開いてね。

### Windows（Python が入っていれば最速）

リポジトリ直下の `起動.bat` をダブルクリック。Python サーバが立ち上がり、ブラウザが自動で開く。終了するときは黒い「dengon-server」窓を閉じる。

### それ以外

リポジトリ直下で:

```sh
python -m http.server 8123
# または: npx serve .
```

そのあとブラウザで `http://localhost:8123/` を開く。

## モーションの追加・差し替え

各場面のモーションは `001_3d/001_motion/<番号_名前>/` に `.fbx`（Mixamo FBX Binary）を置く形式:

| フォルダ | 場面 | ループ |
|---|---|---|
| `01_TOP` | TOP画面のダンス | ループ |
| `02_INPUTNAME` | 人数／名前／順番／タイマー入力中の待機 | ループ |
| `03_NOTCHALL` | ゲーム中：挑戦者以外の待機 | ループ |
| `04_CHALL` | ゲーム中：挑戦者の注目ポーズ | ループ |
| `05_SELECTED` | 読み上げ人に選ばれた時のリアクション | 一回 |
| `06_CORRECT` | 正解者の喜び | 一回 |
| `07_INCORRECT` | 不正解者のがっかり | 一回 |
| `08_WINNER` | 結果発表：1位 | ループ |
| `09_LOSER` | 結果発表：2位以下 | ループ |

**読み込み順の優先度**:
1. `001_3d/001_motion/manifest.json` があれば、それを使う（GitHub Pages 等の本番環境用）。
2. なければ各フォルダのディレクトリ一覧（`起動.bat` の python サーバが返す）から自動検出。
3. それも取れなければ `vrm.js` 内の `MOTION_POOLS[…].files` のハードコードを使う。

**ローカル実行時**は manifest.json がなくても python サーバの一覧取得で自動検出される（フォルダにファイルを置くだけで反映）。

**GitHub Pages 用に追加モーションを反映する**ときは `001_3d/001_motion/manifest.json` に該当プールの配列へファイル名を追記して push。各プールキーは `TOP/INPUTNAME/NOTCHALL/CHALL/SELECTED/CORRECT/INCORRECT/WINNER/LOSER`。

- Three.js + @pixiv/three-vrm（VRM ＋ Mixamo FBX のパイプライン）
- Python http.server（ローカル開発用）
